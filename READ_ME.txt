KRITHIKA — ONE YEAR SINCE HELLO

To personalize the gift (recommended):
1. Open personalize.html in Chrome, Edge, or Safari.
2. Add up to 3 photos of you and Krithika (optional).
3. Edit the letter if you want.
4. Select “Download her surprise” to save a new, self-contained HTML file.
5. Send the file to Krithika as a document, or rename it index.html and upload it to a static website host to create a shareable link.

The original index.html is an already working, ready-to-use gift if you do not want to edit anything.

This is a private, static website with no login, trackers or backend. The page does not upload your photos anywhere. Google Fonts are optional and will only load when there is internet access.
